## 功能

根據關鍵字查詢歌手資料，以及歌手演唱的音樂作品

## 參數

| 名稱 | 說明 | 可選選項 |
|--------| ---------- | ---- |
| keyword | 要查詢的歌手名稱或部分關鍵字（必填） | // |

## 說明

第一次搜尋會顯示符合關鍵字的歌手列表，每頁最多 **5 位**。按下歌手旁的「查看詳情」即可查看該歌手的音樂作品。

作品依評分由高至低排列，每頁最多 **5 筆**，顯示音樂名稱、平均得分、投票數、發售日及所屬遊戲。若來源有提供，也會顯示歌手的 Twitter、Blog 或 Pixiv 連結。

可以透過作品下方的「選擇音樂查看詳細」選單，進一步查看音樂資料；按下「🏠回到主頁」會回到歌手的作品頁面。

歌手或作品超過一頁時，可使用分頁按鈕繼續查看，或用 ⏪／⏩ 跳到第一頁或最後一頁。若找不到預期的歌手，可以縮短關鍵字或改用日文名稱搜尋。
