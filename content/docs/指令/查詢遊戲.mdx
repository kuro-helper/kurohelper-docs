## 說明

輸入至少兩個字元後，會提供最多 **20 筆**遊戲名稱建議。可以選擇建議項目，也可以直接輸入關鍵字後送出；建議名稱來自批評空間，實際查詢來源則依「查詢資料庫選項」決定。

送出後會顯示遊戲列表，每頁最多 **5 筆**，再透過選單查看遊戲詳細資料。若沒有預期中的結果，可以放寬關鍵字或改用其他來源搜尋。

列表可使用 ◀️／▶️ 翻頁；有多頁時也可使用 ⏪／⏩ 跳到第一頁或最後一頁。若按鈕顯示為灰色，代表目前已在該頁，或可直接用上一頁／下一頁到達。

### 個人遊戲狀態

使用**批評空間**查詢時，遊戲列表與詳情會依自己的紀錄，在遊戲名稱旁顯示狀態：

| 標記 | 意義 |
|--------| ---------- |
| ✅ | 已完成 |
| 🎮 | 遊玩中 |
| ⏸️ | 擱置 |
| 🗑️ | 棄坑 |
| ❤️ | 願望清單（已收藏） |

遊玩狀態可以和收藏標記同時顯示。這些是個人紀錄的標記，不是遊戲評分，也不能直接點擊切換狀態。
