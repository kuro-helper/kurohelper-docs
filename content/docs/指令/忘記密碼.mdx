title: 忘記密碼
---

## 功能

透過自己的 Discord 帳號，重設已綁定的 KuroHelper 網站帳號密碼

## 參數

| 名稱 | 說明 | 可選選項 |
|--------| ---------- | ---- |
| password | 新密碼，僅英文與數字，長度需大於 10 碼（必填） | // |
| password_confirm | 再次輸入相同的新密碼（必填） | // |

## 說明

1. 輸入 `/忘記密碼`，填寫新密碼與確認密碼。
2. Bot會顯示只有你看得到的「確認重設密碼」訊息。
3. 按下 ✅ 確認，出現「密碼重設成功」後即可使用新密碼登入網站。

兩次輸入須一致，且密碼不能包含空白或符號。

尚未註冊網站帳號時，請先使用「[註冊帳號](/指令/註冊帳號)」。若確認按鈕已過期，請重新執行指令。

<Callout title="warn" type="warn">重設密碼後，目前已登入的網站不會自動登出。請手動登出，再使用新密碼登入。</Callout>
