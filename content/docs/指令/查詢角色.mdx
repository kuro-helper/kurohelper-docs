## 功能

## 參數

| 名稱 | 說明 | 可選選項 | 預設值 |
|--------| ---------- | ---- | --- |
| keyword | 要查詢的關鍵字 | // | // |
| 查詢資料庫選項 | 要查詢的來源 | **VNDB**, **Bangumi** | **VNDB** |
