## 功能

根據關鍵字查詢音樂資料

## 來源

<Cards>
  <Card title="⭐erogamescape(批評空間)" href="https://erogamescape.dyndns.org/" />
</Cards>

## 參數

| 名稱 | 說明 | 可選選項 |
|--------| ---------- | ---- |
| keyword | 要查詢的關鍵字 | // |

## 說明

輸入至少兩個字元後，會提供最多 **20 筆**音樂名稱建議。可以選擇建議項目，也可以直接輸入關鍵字後送出。

送出後會顯示音樂列表，再透過選單查看詳細資料。有多頁結果時，可使用分頁按鈕，或用 ⏪／⏩ 跳到第一頁或最後一頁。
