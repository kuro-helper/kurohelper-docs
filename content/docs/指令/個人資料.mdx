title: 個人資料
---

## 功能

查看自己的稱號、遊戲紀錄與品牌統計，也可以查詢其他使用者公開的資料

<Callout>第一次使用「簽到」「加已玩」「加收藏」或「註冊帳號」時會自動建立個人資料；網站登入帳號仍需透過「註冊帳號」完成註冊。</Callout>

## 參數

| 名稱 | 說明 | 可選選項 |
|--------| ---------- | ---- |
| user | 要查詢的使用者，不填則查看自己（選填） | 從 Discord 的使用者選單選取 |

## 說明

輸入 `/個人資料` 查看自己；若要查看他人，在 `user` 選取對方即可，不需要手動輸入 Discord ID。對方須已有建檔資料，且未開啟隱私設定。

### 稱號

顯示已獲得的稱號名稱及說明；尚未取得時會顯示「無稱號」。連續「[簽到](/docs/指令/簽到)」達 **100 天**可以獲得簽到稱號。

### 遊戲列表

遊玩狀態與收藏整合在同一份列表，標記顯示在遊戲名稱旁：

| 標記 | 意義 |
|--------| ---------- |
| ✅ | 已完成 |
| 🎮 | 遊玩中 |
| ⏸️ | 擱置 |
| 🗑️ | 棄坑 |
| ❤️ | 願望清單（已收藏） |

遊玩狀態可以和收藏標記同時存在，例如 **🎮 ❤️** 代表遊玩中且已收藏。這些標記用來顯示目前紀錄，不能直接點擊切換狀態。

有記錄遊玩結束日的遊戲會顯示日期。列表每頁最多 **10 筆**，可使用上一頁／下一頁按鈕繼續查看。

### 品牌統計

「玩過最多（公司品牌）」依遊玩數量排列。數量相同的品牌會列在同一星級，最多顯示 **5 個星級**，不一定只有 5 間品牌。

### 隱私設定

可以透過「[帳號設定](/docs/指令/帳號設定)」開啟「隱私遊戲資料」。開啟後其他人無法查詢，自己仍可查看。
