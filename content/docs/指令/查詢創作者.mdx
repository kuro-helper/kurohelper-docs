## 功能

根據關鍵字查詢創作者資料(腳本家、聲優、繪師、音樂製作等)

## 來源

<Cards>
  <Card title="⭐erogamescape(批評空間)" href="https://erogamescape.dyndns.org/" />
</Cards>

## 參數

| 名稱 | 說明 | 可選選項 |
|--------| ---------- | ---- |
| keyword | 要查詢的關鍵字 | // |

## 說明

搜尋後會顯示創作者列表，按下「查看詳情」可查看該創作者參與的遊戲。創作者列表及作品列表每頁最多 **5 筆**，可使用分頁按鈕繼續查看，或用 ⏪／⏩ 跳到第一頁或最後一頁。

作品會顯示該創作者的職務，例如原畫、腳本或聲優；來源有提供時，也會一起顯示更詳細的職務名稱。
